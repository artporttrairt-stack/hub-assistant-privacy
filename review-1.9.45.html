Power Assistant 1.9.45 review workflow

Update to the existing Hub Assistant extension. Store item: akcdhachbpmdfophikblfkghnpnbhhgl. Prepared 15 November 2026.

Account and data boundaries

This is an organization-restricted teacher tool. School-page features require an account issued by VAS for the supported PowerSchool services. There is no public test account. School credentials and student records cannot be shared for review. This guide explains the workflow; it does not provide authentication or bypass access controls.

Do not use another person's account or request real student information for a demonstration. Only school-authorized fictional data is appropriate for functional testing.

Checks without school login

  1. Install the package and open the extension popup. Confirm the name Power Assistant and version 1.9.45.
  2. Open Privacy and switch between English and Vietnamese. Read the supported sites, local processing, optional Teams features and retention disclosures.
  3. Close the notice without accepting it: school assistance remains off. No login credentials are requested by the extension.
  4. Inspect the included code and manifest: packaged JavaScript only; required school hosts are vas.powerschool.com and vas.educator.powerschool.com. Teams hosts and desktop notifications are optional.
  5. Use the public Privacy and Support links. There is no subscription, paywall or developer account.

School workflow with an authorized account

  1. On a school-assigned Mac, open one supported school site using your own permitted account. Review and agree to the privacy notice, then choose the assistance you want. Turning help off must not prevent native school work.
  2. In PowerTeacher Pro, open one current class and its Standards final-grades page. Finish any existing edits using the school's normal process. Use only fictional test entries for this workflow.
  3. Use the existing column filter, including MOET for MOET/DOET columns. A verified comment-only column requires comments, not a grade. Current class is explicit; the extension does not certify other classes.
  4. Open Chart. Review class/student/low-score tabs, resize the window and compare available Unit, Interim 1/2 or EOS1/EOS2 results. Missing milestones stay unavailable. Student IDs bind grades, homeroom and verified portraits; ambiguous names or photo ownership must not be guessed.
  5. Open Print / Export. Prepare a saved-data preview. Draft acknowledgement and privacy acknowledgement are explicit before download. A draft export is labelled DRAFT. Review any workbook import proposal before using it; the extension does not press the final PowerTeacher Save button.
  6. On a supported academic admin report, choose Check reports, read the selected source, review checks and export locally after confirmation. Medical health, allergy and clinic-visit pages have no Hub Check reports entry and are blocked from Hub reads/add-source/export, even with privacy agreement. Academic Health Education is not a medical report.
  7. For communication support, select the class (class code first), add recipients and use the shared Review bar. Opening Teams prepares a chat; it never presses Send. Teams portraits and draft checks are separate opt-ins. The movable countdown must leave Teams controls usable and hide without safe space.
  8. Change class, term or supported page, or withdraw privacy agreement. Old pending results and associated detailed session data are released. Settings/calendars remain as disclosed.

What changed in this update

New name, resizable score analytics, native comment-only handling, MOET/DOET filtering, safer student/photo mapping, grouped Teams recipient review, optional Teams countdown, medical-report exclusion and clearer download confirmations.

All code is packaged locally. Links to Microsoft/Copilot are user-initiated; the extension does not automatically upload reports to an AI provider. Selected recipient addresses and prepared Teams text are passed through the user-opened Teams link and are subject to Microsoft policies.

Validation scope

Local synthetic regression, native-adapter and browser checks passed before packaging. They do not establish every school configuration or replace authenticated teacher acceptance. PowerSchool was unavailable for the final native-page check. Reviewers should not interpret these tests as live data access or a guarantee of approval.
