English

1. What Hub Assistant is

Hub Assistant is a teacher-facing browser extension that provides contextual guidance on supported PowerSchool / PowerHub educator pages. It helps teachers understand interface context and complete workflows while keeping final actions under teacher control.

Hub Assistant is independently developed by A.I MY. It is not an official PowerSchool, Microsoft, or Google product and does not claim endorsement by those companies.

The current release is limited to two supported VAS PowerSchool origins: https://vas.educator.powerschool.com/* for PowerHub educator workflows and https://vas.powerschool.com/* for PowerSchool SIS / PowerTeacher workflows.

2. Intended users

Hub Assistant is designed for teachers and authorized school staff. It is not designed as a student-facing service, social network, advertising service, or student profiling system.

If a future deployment changes the intended audience or makes the extension directly available to children, the privacy and safeguarding design must be reassessed before that deployment.

3. Information the extension may access locally

To provide teacher-facing guidance, the extension may read information already visible in the supported PowerSchool / PowerHub page when relevant, including:

  • names displayed by PowerSchool;
  • student, guardian, or account role labels;
  • class, audience, and relationship context used to identify the correct teacher workflow;
  • interface state, buttons, dialogs, tabs, and navigation context;
  • information displayed within Messages or Newsfeed surfaces when needed to determine the current guidance state;
  • assistant-language and display preferences; and
  • walkthrough, onboarding, and contextual-help progress.

For the teacher-enabled SIS Vietnamese natural-name display, the extension may request the active section roster from PowerSchool's same-origin /ws/xte/student endpoint using the existing signed-in PowerSchool session. The response is processed transiently to build a display-name map.

This access is limited to the two supported PowerSchool origins declared by the current manifest/content-script configuration. The SIS roster request is sent to PowerSchool, not to A.I MY.

4. Information the extension does not intentionally collect

The current release does not intentionally collect or create a database of passwords, authentication cookies or tokens, payment information, health information, precise location, unrelated browsing history, advertising identifiers, student behavioral profiles, persistent student nicknames, or persistent student-profile records.

Hub Assistant does not use A.I MY analytics, telemetry, advertising trackers, or behavioral advertising in the current release.

5. How personal information is processed

Names and other PowerSchool identity context may be processed transiently in the browser while a supported page is active so the extension can provide the requested teacher-facing guidance.

The current release uses in-memory page/runtime structures for transient student/guardian identity context. For SIS Vietnamese-name display, the current-section roster payload is processed transiently and reduced to a RAM-only name map; student names, PowerSchool IDs, Student Code, roster payloads, and name maps are not persisted by that feature.

The extension does not send student names, guardian names, message content, Newsfeed content, SIS roster data, or teacher workflow data to a server controlled by A.I MY or to an analytics provider.

When SIS Vietnamese-name display is enabled, Hub Assistant itself initiates a same-origin roster request to PowerSchool. That request uses the existing signed-in PowerSchool session and stays within the PowerSchool service; it is not an A.I MY data transmission.

6. Information stored by the extension

The extension uses the browser extension storage capability for product settings and progress, including:

  • assistant language/reference choices;
  • walkthrough and onboarding progress;
  • contextual-help preferences;
  • SIS Vietnamese-name display opt-in (a boolean preference only); and
  • other extension state required to continue the teacher-facing experience.

These settings are not intended to store student or guardian profiles. For SIS Vietnamese-name display, only sisVietnameseNameDisplayEnabledV1=true is persisted after teacher opt-in; student names, PowerSchool IDs, Student Code, roster payloads, and name maps remain RAM-only.

Earlier development versions used legacy student nickname/profile and SIS name-prototype storage keys. The current release removes obsolete nickname/profile keys such as studentNicknames, studentProfiles, and psqmStorageVersion, and purges obsolete SIS prototype name-display state.

7. Sharing and external transmission

The current release does not sell or broker personal information; share student or guardian information with advertisers; transmit student, guardian, message, Newsfeed, or SIS roster data to an A.I MY backend; use third-party analytics or telemetry services; use Microsoft Graph, Google Identity, or another cloud identity service; or synchronize a student nickname/profile database to the cloud.

The SIS roster request described above goes only to PowerSchool. The help interface may also offer a user-initiated link to Microsoft 365 Copilot; Hub Assistant does not append or prefill PowerSchool, student, guardian, message, or roster content into that link.

If a future version introduces any external service or materially different data use, this policy and the browser-store disclosures must be updated before that version is released.

8. Child safeguarding and educational use

Hub Assistant follows a data-minimization approach. Student/guardian identity context is used only when necessary for a teacher-facing workflow. The current release does not build commercial or behavioral profiles of children, does not display advertising, and does not automatically perform final teacher actions such as Send, Create Group, or Publish.

PowerSchool / PowerHub remains the authoritative source of school data and workflow state.

9. Teacher control

Hub Assistant may guide or assist intermediate interface steps, but final consequential actions remain teacher-controlled. The current release does not automatically execute the final Send, Create Group, or Publish action on behalf of the teacher.

10. Security design

The current manifest uses Manifest V3 and requests only the storage permission. Content scripts are scoped to https://vas.educator.powerschool.com/* and https://vas.powerschool.com/*. The audited Hub Assistant 1.9.24 / FIX22.4 runtime does not include remote executable code, external analytics, network-fetch logic for an A.I MY service, eval, new Function, XMLHttpRequest, or WebSocket. Its SIS name-display module does use fetch() for the same-origin PowerSchool roster endpoint described above.

The audited session-timeout helper validates the native timeout dialog but does not click Stay Signed In or silently extend a PowerSchool login session.

11. Retention and deletion

Hub Assistant does not intentionally persist student nickname/profile or SIS roster records in the current release. Transient page/runtime identity context, roster responses, and SIS name maps last only as needed for the active browser/page workflow. The SIS name-display opt-in and other extension preferences/progress may remain in browser extension storage until cleared through browser/extension administration or the extension is removed, subject to browser behavior and school device-management policy.

Legacy nickname/profile keys are targeted for removal during install/update as described above.

12. GitHub Pages website hosting

This privacy/support website contains no A.I MY analytics, advertising, tracking scripts, data-entry forms, or external JavaScript. It is hosted using GitHub Pages. GitHub states that visitor IP addresses are logged and stored for security purposes when GitHub Pages sites are visited. That hosting-provider processing is separate from the Hub Assistant browser extension.

See GitHub's own privacy documentation for GitHub-hosted infrastructure practices.

13. School deployment and account model

This policy does not assume a particular Edge profile, Chrome profile, managed-browser configuration, or device-sharing model. Schools should separately determine appropriate account, device-sharing, access-control, retention, user-notice, and incident-handling practices.

14. Policy changes

This policy should be reviewed whenever the extension adds a new permission, broader host access, external service, analytics capability, identity provider, persistent student-data feature, student-facing workflow, or materially different teacher workflow.

Chính sách quyền riêng tư

1. Hub Assistant là gì

Hub Assistant là tiện ích trình duyệt dành cho giáo viên, cung cấp hướng dẫn theo ngữ cảnh trên các trang PowerSchool / PowerHub dành cho giáo viên được hỗ trợ. Các hành động cuối cùng vẫn do giáo viên kiểm soát.

Hub Assistant được A.I MY phát triển độc lập. Đây không phải sản phẩm chính thức của PowerSchool, Microsoft hoặc Google và không tuyên bố được các công ty này bảo trợ hay chứng nhận.

Build hiện tại chỉ hoạt động trên hai origin VAS PowerSchool được hỗ trợ: https://vas.educator.powerschool.com/* cho PowerHub và https://vas.powerschool.com/* cho PowerSchool SIS / PowerTeacher.

2. Đối tượng sử dụng

Hub Assistant được thiết kế cho giáo viên và nhân viên trường học được ủy quyền. Tiện ích không được thiết kế như dịch vụ dành trực tiếp cho học sinh, mạng xã hội, dịch vụ quảng cáo hay hệ thống lập hồ sơ học sinh.

Nếu cách triển khai trong tương lai thay đổi đối tượng và cho trẻ em sử dụng trực tiếp, thiết kế quyền riêng tư và safeguarding phải được đánh giá lại trước khi triển khai.

3. Thông tin tiện ích có thể đọc cục bộ

Để cung cấp hướng dẫn cho giáo viên, tiện ích có thể đọc thông tin đang hiển thị trên trang PowerSchool / PowerHub được hỗ trợ khi cần, gồm tên do PowerSchool hiển thị, vai trò tài khoản, ngữ cảnh lớp/audience/quan hệ, trạng thái giao diện, nội dung đang hiển thị trong Messages hoặc Newsfeed khi cần xác định bước hướng dẫn, và các lựa chọn/ngữ cảnh tiến độ của chính extension.

Đối với chức năng đổi tên tự nhiên tiếng Việt trong SIS do giáo viên chủ động bật, extension có thể gọi roster của section hiện tại từ endpoint cùng origin của PowerSchool /ws/xte/student bằng phiên PowerSchool đang đăng nhập. Response chỉ được xử lý tạm thời để tạo name map hiển thị.

Quyền truy cập này chỉ giới hạn ở hai origin PowerSchool được hỗ trợ. Roster SIS được gửi/nhận với PowerSchool, không gửi tới A.I MY.

4. Thông tin tiện ích không chủ động thu thập

Build hiện tại không chủ động tạo cơ sở dữ liệu về mật khẩu, cookie/token xác thực, dữ liệu tài chính, dữ liệu sức khỏe, vị trí chính xác, lịch sử duyệt web không liên quan, advertising identifier, hồ sơ hành vi học sinh, nickname học sinh lưu lâu dài hoặc hồ sơ học sinh lưu lâu dài.

Build hiện tại không sử dụng analytics, telemetry, quảng cáo theo dõi hoặc quảng cáo hành vi của A.I MY.

5. Cách xử lý dữ liệu cá nhân

Tên và ngữ cảnh định danh từ PowerSchool có thể được xử lý tạm thời trong trình duyệt khi trang được hỗ trợ đang hoạt động để cung cấp hướng dẫn cho giáo viên. Với chức năng đổi tên SIS, roster của section hiện tại chỉ được xử lý tạm thời để tạo name map trong RAM; tên học sinh, PowerSchool ID, Student Code, roster payload và name map không được lưu lâu dài bởi chức năng này.

Build hiện tại không gửi tên học sinh, tên người giám hộ, nội dung tin nhắn, nội dung Newsfeed, roster SIS hoặc dữ liệu workflow của giáo viên tới máy chủ do A.I MY kiểm soát hoặc nhà cung cấp analytics. Request roster do extension khởi tạo chỉ đi tới PowerSchool cùng origin.

6. Dữ liệu extension lưu

Extension sử dụng khả năng storage của trình duyệt để lưu cài đặt và tiến độ sản phẩm, ví dụ:

  • lựa chọn ngôn ngữ/ngôn ngữ tham chiếu của trợ lý;
  • tiến độ walkthrough và onboarding;
  • tùy chọn contextual help;
  • opt-in đổi tên tự nhiên tiếng Việt trong SIS (chỉ là một boolean); và
  • trạng thái extension cần thiết để tiếp tục trải nghiệm hướng dẫn.

Các setting này không nhằm lưu hồ sơ học sinh hoặc người giám hộ. Với chức năng đổi tên SIS, chỉ sisVietnameseNameDisplayEnabledV1=true được persist sau khi giáo viên opt-in; tên, ID, Student Code, roster payload và name map vẫn chỉ ở RAM.

Để dọn dữ liệu từ phiên bản cũ, build hiện tại xóa các key nickname/profile cũ như studentNicknames, studentProfiles, psqmStorageVersion và purge state prototype đổi tên SIS đã lỗi thời.

7. Chia sẻ và truyền dữ liệu ra ngoài

Build hiện tại không bán hoặc môi giới dữ liệu cá nhân, không chia sẻ dữ liệu học sinh/người giám hộ cho nhà quảng cáo, không truyền dữ liệu học sinh/người giám hộ/tin nhắn/Newsfeed/roster SIS tới backend A.I MY, không dùng analytics/telemetry của bên thứ ba, không dùng Microsoft Graph/Google Identity hoặc dịch vụ cloud identity khác và không đồng bộ cơ sở dữ liệu nickname/hồ sơ học sinh lên cloud.

Request roster SIS chỉ đi tới PowerSchool. Giao diện trợ giúp cũng có thể cung cấp link do người dùng chủ động mở tới Microsoft 365 Copilot; Hub Assistant không gắn hoặc prefill nội dung PowerSchool, học sinh, người giám hộ, tin nhắn hay roster vào link đó.

Nếu phiên bản tương lai thêm dịch vụ bên ngoài hoặc thay đổi đáng kể cách dùng dữ liệu, policy và store disclosure phải được cập nhật trước khi phát hành phiên bản đó.

8. Safeguarding trẻ em

Hub Assistant áp dụng nguyên tắc giảm thiểu dữ liệu. Ngữ cảnh học sinh/người giám hộ chỉ được dùng khi cần cho workflow của giáo viên. Build hiện tại không lập hồ sơ thương mại/hành vi của trẻ em, không hiển thị quảng cáo và không tự động thực hiện hành động cuối cùng như Send, Create Group hoặc Publish.

PowerSchool / PowerHub vẫn là nguồn dữ liệu và trạng thái workflow chính thức.

9. Quyền kiểm soát của giáo viên

Hub Assistant có thể hướng dẫn bước trung gian nhưng hành động cuối cùng có hậu quả vẫn do giáo viên kiểm soát. Tiện ích không tự động thực hiện Send, Create Group hoặc Publish thay giáo viên.

10. Thiết kế bảo mật

Manifest hiện tại dùng Manifest V3 và chỉ yêu cầu quyền storage. Content script được giới hạn ở https://vas.educator.powerschool.com/* và https://vas.powerschool.com/*. Runtime Hub Assistant 1.9.24 / FIX22.4 đã audit không chứa remote executable code, external analytics, network-fetch logic tới dịch vụ A.I MY, eval, new Function, XMLHttpRequest hoặc WebSocket. Module đổi tên SIS có dùng fetch() tới endpoint roster cùng origin của PowerSchool như mô tả ở trên.

Helper session-timeout đã audit chỉ xác thực dialog timeout native; nó không bấm Stay Signed In và không âm thầm kéo dài phiên đăng nhập PowerSchool.

11. Lưu giữ và xóa dữ liệu

Hub Assistant không chủ động lưu lâu dài nickname/hồ sơ học sinh hoặc roster SIS trong build hiện tại. Ngữ cảnh định danh, roster response và SIS name map tạm thời chỉ tồn tại khi cần cho workflow trang/browser đang hoạt động. Boolean opt-in đổi tên SIS cùng các setting/tiến độ khác của extension có thể còn trong browser extension storage cho tới khi được xóa bởi quản trị trình duyệt/extension hoặc extension bị gỡ.

Các key nickname/hồ sơ cũ được nhắm tới để xóa trong quá trình install/update như mô tả ở trên.

12. Hosting website bằng GitHub Pages

Website privacy/support này không chứa analytics, quảng cáo, tracking script, form nhập dữ liệu hoặc external JavaScript của A.I MY. Website được host bằng GitHub Pages. Theo tài liệu GitHub, địa chỉ IP của người truy cập GitHub Pages có thể được GitHub ghi nhận và lưu cho mục đích bảo mật. Việc xử lý ở tầng hosting này tách biệt với Hub Assistant extension.

13. Triển khai tại trường

Policy này không giả định mỗi giáo viên có profile Edge/Chrome riêng hoặc một mô hình thiết bị cụ thể. Trường cần đánh giá riêng account, thiết bị dùng chung, access control, retention, user notice và quy trình xử lý sự cố.

14. Thay đổi policy

Policy cần được xem lại trước khi phát hành phiên bản thêm permission/host mới, backend ngoài, analytics, identity provider, dữ liệu học sinh lưu lâu dài, student-facing workflow hoặc workflow giáo viên thay đổi đáng kể.
